# Bishu Tiwari — Portfolio

A responsive personal portfolio for Bishu Tiwari, built with plain HTML, CSS and JavaScript.

## Features

- Modern dark Cloud/DevOps aesthetic
- Fully responsive layout
- Animated reveal effects
- Interactive mobile navigation
- Terminal-inspired hero section
- Skills, projects, education, achievements and certifications
- GitHub, LinkedIn and email CTAs
- No framework or build step required

## Run locally

Open `index.html` in your browser.

Or use a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize

Edit `index.html` for content and links.

Edit `style.css` to change the visual design.

Edit `script.js` for interactions.

Replace the placeholder LinkedIn URL and update the GitHub URL if your repository username differs.
